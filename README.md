# Lab2

Проект содержит функции для вычисления площади и периметра геометрических фигур на языке Python.

## Поддерживаемые фигуры

В проекте реализованы три геометрические фигуры:

* **Circle** — круг;
* **Rectangle** — прямоугольник;
* **Square** — квадрат.
